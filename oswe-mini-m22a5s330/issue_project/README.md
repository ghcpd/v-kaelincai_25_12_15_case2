Issue Project — Greenfield Replacement Design and Tests

This repository contains an artifact set for analyzing a legacy appointment/ranking system and demonstrating a greenfield replacement with integration tests and mocks.

Quick start

1. Setup environment: sh setup.sh
2. Start calendar mock: python -m issue_project.mocks.calendar_mock &
3. Run tests: sh run_tests.sh

See DESIGN.md for full analysis and replacement plan.
